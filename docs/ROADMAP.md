# 路线图（5.0 之后）

> 5.0.0：现代浏览器基线（Custom Elements、WAAPI、IntersectionObserver、ResizeObserver、adoptedStyleSheets），移除 4.9 弃用的 API，新增统一的插件式效果注册（`registerEffect()` / `playEffect()` / `<usa-fx>`）。以下为 5.x → 6.0 的规划，每个版本一个 PR；新效果全部通过注册表提供，集中在新入口 `use-scroll-animate/components/effects`（不计入 `components/lite` 的 70 KB 预算）。

- ✅ **v5.1** — 卡片与点击特效 2.0：全息镭射卡、扫光、3D 翻书、磁吸卡组、卡片倾倒；点击冲击波环、墨水飞溅、星星爆裂、果冻按压、涟漪环 —— 全部可用 `<usa-fx>` 触发。
- ✅ **v5.2** — 弹跳与物理微交互：弹入、橡皮筋、弹性悬停、掉落回弹、重力文字、弹簧跟随指针、摇摆铃铛。
- ✅ **v5.3** — 全页特效：幕布、光圈擦除、像素溶解、百叶窗转场、滚动速度倾斜、全页聚光灯、页面边缘光晕。
- ✅ **v5.4** — 滚动叙事模板：`<usa-story>` —— 固定章节、横向长廊、缩放穿越、前后对比滑块、数据故事计数器、逐段高亮。
- ✅ **v5.5** — 生成式背景：流场、Voronoi 细胞、网格渐变（mesh gradient）、星空、metaballs、等高线 —— Canvas 2D 实现，可见时才渲染，自适应质量。
- **v5.6** — 声音响应特效：Web Audio 分析器驱动频谱柱、脉冲光环、波形环，节拍检测可触发任意已注册效果（需用户手势开启，减少动态效果时停用）。
- **v5.7** — 光标与手势包：彗星拖尾、星光、丝带、磁吸点、聚光光标；甩动、双指旋转、长按蓄力手势 → 触发效果。
- **v5.8** — 主题包与微交互库：霓虹、纸张、玻璃、复古、粗野主义主题包（令牌 + 效果预设）；复制成功、开关变形、输入抖动、密码显隐、收藏星星、下载进度等 20+ 微交互。
- **v5.9** — JSON 动画播放器 + 6.0 预备：`<usa-player>` 播放 JSON 动画（关键帧轨道 + 已注册效果，可由实验室导出）；标记 6.0 将移除的 API 并输出一次性警告，发布 `upgrading-6.md` 与 `usa-codemod-6`。
- **v6.0** — 破坏性清理：移除 5.9 弃用的 API，效果统一走注册表，迁移指南与自动迁移脚本，npm `latest`。
