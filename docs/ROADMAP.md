# Motionary 路线图（7.0 之后）

7.0 已发布：移除 6.9 弃用项、按效果包拆分入口（`motionary/fx/*`）、着色器背景默认 WebGPU（自动回退 WebGL2 → Canvas 2D），`motionary` 与 `use-scroll-animate` 同时成为 npm `latest`。下面是 7.1 → 8.0 的计划，每个版本一个特效主题 + 一组新的动画组件。

- ✅ **v7.1** — 音乐可视化：频谱柱、波形、节拍脉冲、唱片旋转；新组件 音乐播放器、音量旋钮、均衡器。
- **v7.2** — 数据可视化动效：柱状 / 折线 / 环形 / 桑基图入场与数值过渡；新组件 仪表盘（Gauge）、迷你走势图（Sparkline）、KPI 指标卡。
- **v7.3** — 电商动效：飞入购物车、价格翻牌、库存脉冲、优惠券撕开；新组件 购物车抽屉、商品图库、限时倒计时。
- **v7.4** — 聊天 / 社交：输入中气泡、表情回应飘升、已读回执、消息撤回；新组件 消息列表、头像叠放、通知铃铛。
- **v7.5** — 游戏化：成就解锁、经验条、宝箱开启、幸运转盘；新组件 排行榜、徽章墙、抽奖机。
- **v7.6** — 地图与地理：路线绘制、旋转地球、标记脉冲、飞线；新组件 3D 地球、位置卡片。
- **v7.7** — 表单动效：抖动校验、浮动标签、密码强度、成功勾选；新组件 动效输入框、验证码（OTP）输入、上传进度。
- **v7.8** — AI 界面：流式文字、思考光晕、语音波形、生成骨架；新组件 对话输入框、建议标签（Chips）、语音按钮。
- **v7.9** — 8.0 预备：8.0 弃用警告、`upgrading-8.md` 与 `usa-codemod-8`；新组件 命令面板（⌘K）、快捷键提示。
- **v8.0** — 统一时间线引擎（所有组件与特效共享一个时钟）、SSR 水合动画、移除 7.9 弃用项；npm `latest`。
