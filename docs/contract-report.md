# Component contract report

Generated by `node scripts/contract-audit.mjs` against the rules of [component-contract.md](./component-contract.md). Report only in 11.x — 12.0 makes the contract test blocking.

**207 components · 164 without findings · 102 findings · 16 documented exemptions.**

| Rule | Contract part | Findings | What it means |
|---|---|---|---|
| `attr-unobserved` | attributes | 102 | reads an attribute (str/num/flag) that is not in observedAttributes — changing it later has no effect |
| `event-prefix` | events | 0 | dispatches a CustomEvent whose name does not start with `usa:` (use this.emit()) |
| `event-bubbles` | events | 0 | dispatches a CustomEvent without bubbles: true (this.emit() bubbles and composes) |
| `keyboard-click-only` | keyboard | 0 | reacts to click / pointer input on the host but has no keyboard handling and no native control inside |
| `lifecycle-global-listener` | lifecycle | 0 | adds a window / document listener directly — not removed on disconnect (use this.listen()) |
| `lifecycle-timer` | lifecycle | 0 | starts setInterval without clearing it on disconnect (onCleanup / clearInterval) |
| `reduced-motion` | reduced motion | 0 | animates (el.animate / requestAnimationFrame loop) without checking reduced motion (this.reduced, this.motion(), prefersReducedMotion()) |
| `error-prefix` | errors | 0 | throws / logs a message that does not start with `[motionary]` |
