# Motionary 17.x 维护计划

更新时间：2026-11-07。已合并基线：`17.2.0`，main `3de2595a`。本轮准备 `17.2.1`，发布状态以 Release 为准。
本计划基于当前源码、测试、CI 和 [稳定性约定](stability.md)，替代旧计划中尚未执行的版本预测。
版本号是目标范围；未合并、未发布的工作不标记为已发布。

## 执行原则

- 延续 16.3 后的方向：维护已有能力；按本轮需求升级现有交互动效与组件，不增加新的大型运行时。
- 核心零运行时依赖；lite ≤ 71,680 B gzip；`components/mo` ≤ 2,048 B gzip；其他预算保持原值。
- `usa-*` 与 `mo-*` 并存，事件继续使用 `usa:*`；Scene v3 保持兼容，保留已承诺的迁移路径。
- Studio、插件 API、MCP、AI、Figma 和跨平台导出仍为实验性，不因修复或补测试就改称稳定。
- 一个修复主题一个 PR；每轮必需 CI 通过且无已知重大缺陷后直接合并，按 SemVer 发布并提供可下载包体，无需逐次确认。`dist/` 只在发布 PR 更新，外部条件阻塞时明确保留未发布状态。
- 真机、读屏和原生编译尚未完成的项目保持待验证；不把模拟器结果写成真机结论。

## 17.1 交互与液态导航更新

- 修复按压状态残留、子元素失焦后键盘按压不释放，以及磁吸待执行帧在失焦后重新激活的问题。
- 液态导航新增纵向布局、RTL 方向键与 Home/End，连续切换从当前视觉位置衔接，尺寸变化后自动对齐。
- 修复 value 属性更新和重新挂载时的选中项一致性，卸载时释放帧、动画和尺寸观察器。
- 补充单元及三浏览器回归，保持原固定体积上限。此项是 M17-002 的交互生命周期子集，其余命名与加载矩阵继续按计划推进。
- [PR #175](https://github.com/HarrisonCN/Motionary/pull/175) 已合并并发布 17.1.0。

## 17.2 命令面板交互

- 新增 Page Up / Page Down 按可视高度翻页，保留输入焦点。修复输入法确认时误执行命令、退场时重复触发事件和重新挂载后旧动画抢焦点。
- 此轮推进 M17-005 的键盘交互部分。M17-002 的加载矩阵与 M17-003 的工程一致性仍待验证。

## 17.2.1 按需样式加载

- 19 个分类逐一检查新旧标签的映射。组件首次挂载请求所属分类的 CSS，同分类的并发挂载共用请求。
- 回归场景包含首次请求失败后由旧标签重试、已挂载新标签收到样式以及再次挂载时复用成功请求。
- 前一轮命令面板已随 [17.2.0](https://github.com/HarrisonCN/Motionary/releases/tag/v17.2.0) 发布。

## 每轮完成条件

1. 从最新 main 与开放 PR 复核基线，避免覆盖已完成或进行中的工作。
2. 回归测试证明问题存在；修复后的测试验证实际行为。
3. 运行 `npm run typecheck`、`npm test`、构建及受影响的体积 / 文档 / 浏览器检查。
4. 以 PR 头提交的 Node 20/22/24、Chromium/Firefox/WebKit 等必需 CI 为合并依据，遵守 [release gate](release-gate.md)。
5. 更新本页的完成项、验证结果、PR 和下一项。发布另走现有发布流程，不用计划状态代替 Release。

## 与 Gateway 的依赖关系

M17-004 与 Gateway 的 G17-003 使用同一组固定版本语料；任一方升级后都执行工具发现 → 提案 → 校验 → 接受 / 拒绝 → 溯源测试。
Gateway 17.0 已发布，但其专用硬件长稳 / 基线和外部安全审查仍未完成；互通通过不等于这些闸门通过。
