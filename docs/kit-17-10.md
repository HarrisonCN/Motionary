# UI, Components & Motion (17.10)

Twenty-one independently importable widgets in three groups of seven: page-level UI blocks, data and media components,
and motion surfaces. Every element registers its `mo-*` name directly; the `usa-*` names stay available. No runtime
dependency, network request, third-party code, font or image is bundled.

## Scope

The list comes from Motionary's own roadmap backlog (navigation, marketing blocks, data display, galleries and the
scroll and cursor effects still missing from the gallery). These are original implementations written against
Motionary's element base, spring physics and contract rules.

Each widget enhances what is already in its children. Without JavaScript the content is shown as written: links stay
links, the table stays a table, pictures stay pictures. Under `prefers-reduced-motion` they show the end state
straight away (the image trail and the scroll velocity effect do nothing at all, the horizontal scroll section becomes
a plain snap scroller).

## UI blocks

| Element | Built on | Main attributes | Events |
|---|---|---|---|
| `mo-sidebar` | `nav` with the child links / buttons | `label`, `collapsed`, `expand-label`, `collapse-label` | `usa:toggle { collapsed }`, `usa:select { index, item }` |
| `mo-scrollspy` | `nav` + ordered list, `aria-current="location"` | `target`, `selector` (`h2[id], h3[id]`), `label`, `offset` (80) | `usa:change { id, index }` |
| `mo-pricing` | radio switch + plan cards from `data-name`, `data-monthly`, `data-yearly` children | `period`, `currency`, `locale`, `label`, `monthly-label`, `yearly-label`, `yearly-note`, `month-unit`, `year-unit` | `usa:change { period }`, `usa:select { plan, period, price }` |
| `mo-announcement-bar` | `role="region"` with a pause button | `interval` (2500–20000; 5000), `dismissible`, `tone`, `label`, `close-label` | `usa:change { index }`, `usa:dismiss` |
| `mo-sticky-cta` | fixed bar, `inert` while hidden | `watch` or `offset` (320), `position`, `dismissible`, `label`, `close-label` | `usa:show`, `usa:hide`, `usa:dismiss` |
| `mo-bento` | CSS grid of the children (`data-span`, `data-rows`) | `columns` (2–6; 4), `gap`, `collapse` (560), `stagger` (70) | none |
| `mo-empty-state` | heading + text + the child actions | `icon` (inbox, search, folder, cloud, bell, cart), `heading`, `description`, `heading-level`, `compact` | none |

## Components

| Element | Built on | Main attributes | Events |
|---|---|---|---|
| `mo-lightbox` | native `<dialog>` opened with `showModal()` | `label`, `loop`; full image from `data-full` or a wrapping `a href` | `usa:open { index }`, `usa:change { index }`, `usa:close` |
| `mo-data-table` | the child `<table>`, header sort buttons, `aria-sort` | `filterable`, `filter-label`, `placeholder`, `sort-column`, `sort-direction` | `usa:sort { column, direction }`, `usa:filter { query, count }` |
| `mo-filter-chips` | toggle buttons with `aria-pressed` | `options`, `value`, `target` (next sibling), `multiple`, `match` (any or all), `label`, `all-label` | `usa:change { value, count }` |
| `mo-hotspots` | the child picture + buttons with `aria-expanded` | `pulse` (once, loop, off), `label`; notes from `data-x`, `data-y`, `data-title` children | `usa:open { index }`, `usa:close` |
| `mo-fan-carousel` | region with previous / next buttons; back cards `inert` | `index`, `spread` (3–20; 9), `loop`, `label` | `usa:change { index }` |
| `mo-expand-cards` | buttons over `data-title` / `data-image` panels | `index`, `trigger` (hover or click), `stack` (640), `label` | `usa:change { index }` |
| `mo-json-viewer` | ARIA tree with arrow-key navigation | `json` or a child `script[type=application/json]` or the `data` property, `expand-depth` (1), `max-nodes` (2000), `label` | `usa:toggle { path, open }` |

`mo-json-viewer` writes every key and value as text, never as markup. `mo-lightbox` only opens http(s), relative and
`data:image` addresses (`safeImageUrl`).

## Motion surfaces

| Element | What moves | Main attributes | Events |
|---|---|---|---|
| `mo-scroll-velocity` | children skew, stretch, blur or tilt with scroll speed (`--vel`, `--vel-abs`) | `mode` (skew, stretch, blur, tilt), `strength`, `max` | none |
| `mo-horizontal-scroll` | panels travel sideways while the page scrolls down (sticky pin) | `panel-width` (80vw), `gap`, `progress`, `min-width` (640), `label` | `usa:change { index }` |
| `mo-image-trail` | the child `img` pool drops behind the pointer (decorative, mouse only) | `distance`, `life`, `max`, `size` | none |
| `mo-hover-reveal-list` | a picture from `data-image` follows the pointer on a spring and leans with its speed | `size`, `tilt`, `label` | `usa:change { index }` |
| `mo-liquid-glass` | blurred, refracted backdrop with a pointer highlight; squash on press | `strength`, `blur`, `tint`, `radius`, `pressable` | none |
| `mo-path-motion` | children ride an SVG path, turning with it and drawing it | `path`, `trigger` (scroll, view, loop, hover), `duration`, `rotate`, `trace`, `spacing`, `show-path`; property `progress` | `usa:done` |
| `mo-cut-reveal` | copies of the content are sliced, shredded, split or torn and fly together | `cut` (slice, shred, split, tear), `pieces`, `duration`, `trigger` (view or manual); method `play('in' \| 'out')` | `usa:done { direction }` |

The refraction in `mo-liquid-glass` uses an SVG filter on the backdrop, which only Chromium supports; other browsers
get the frosted glass without the bend. The `loop` mode of `mo-path-motion` adds a pause button and stops while off
screen. The copies made by `mo-cut-reveal` are `aria-hidden`, `inert` and have their ids removed; the real content only
turns transparent while they move, so it keeps its place in the layout and in the accessibility tree.

## Theming

The widgets share one set of tokens, overridable on any ancestor: `--mo-kit-ink`, `--mo-kit-paper`, `--mo-kit-accent`,
`--mo-kit-on-accent`, `--mo-kit-soft`, `--mo-kit-line` and `--mo-kit-radius`.

## Use

```js
import { definePricing } from 'motionary/widgets/pricing';
definePricing();
```

`defineWidgets('17.10')` registers all twenty-one. The pure helpers are exported from `motionary/widgets` for tests
and custom layouts: `flip`, `measure`, `tween`, `safeImageUrl`, `sortKey`, `compareKeys`, `fanPose`, `jsonPath`,
`velocityAmount`, `trackOffset`, `cleanPathData` and `stripClips`.
