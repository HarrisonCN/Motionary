17.6 / MATTER & MOTION

让界面有一点
物理直觉。

粒子会被吸引，液面会慢慢回稳，文字也可以被仔细观察。
13 个可独立使用的组件，6 个随时能接入的动效。

API 与参考 ↗
桌面：直接移动指针。触屏：点 Interact 后拖动，Done 退出。键盘可用 · 尊重减少动态效果 · 无外部素材
01 / ACCRETION↗

引力不是一条直线。

移动指针吸引粒子，按住聚拢。

mo-gravity-well
02 / MERCURY↗

像水银一样有张力。

点阵的金属液珠，随拉拽分离与融合。

mo-liquid-metal
03 / CHEMISTRY↗

图案，自己生长。

按住绘制；等高线模式下按住擦除。

mo-reaction-field
04 / ADVECTION↗

搅动两种颜色。

移动指针，改变灰蓝墨流的方向。

mo-ink-flow
05 / LEVEL↗

文字也能盛下水。

移动指针或用方向键，让液面倾斜。

mo-fluid-type
06 / ALIGNMENT↗

让微小的方向一致。

指针是一枚磁偶极子，线段随之转向。

mo-magnetic-field
07 / TENSION↗

拉开，再慢慢松手。

锚定的网格节点用弹簧恢复位置。

mo-elastic-mesh
08 / SPRING↗

把弹性变成参数。

用原生滑块调整质量、刚度和阻尼。

mo-spring-lab
09 / TIMING↗

一条曲线，另一种节奏。

拖动蓝色控制点，或用滑块精确调节。

mo-bezier-lab
10 / LOUPE↗

把小字看清楚。

指针与键盘可用的放大镜，原文始终可读。

mo-text-loupe
11 / REVISION↗

从草稿，走到定稿。

横向揭示两份内容，对照每一次修改。

mo-revision-reveal
12 / INTENT↗

让确认有一点重量。

长按完成；松开或 Escape 取消，仅触发事件。

等待长按
mo-hold-action
13 / PRECISION↗

数值，也有手感。

直接输入，或横向拖动。Shift 细调。

mo-scrub-number
