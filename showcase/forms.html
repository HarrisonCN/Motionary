17.7 / FORM ATELIER

细节，在每一次
输入之间。

选择、搜索、微调、确认。让表单操作更清楚，也更有手感。
九个独立组件，四个描线反馈。支持键盘、表单重置和减少动态效果。

01 / NATIVE SELECT

原生精细选择器

原生选择、分组、表单校验与重置。

<mo-select>
02 / SEARCH COMBOBOX

搜索选择框

搜索选项、跳过禁用条目，选择时保留输入焦点。

<mo-combobox>
03 / TOKEN MULTI-SELECT

标签多选器

筛选原生复选框、移除标签，并提交多个表单值。

<mo-multi-select>
04 / NUMBER STEPPER

精度数值步进

小数精度、原生数值输入、上下界按钮与表单重置。

<mo-number-stepper>
05 / PRIVATE PASSWORD FIELD

密码显隐输入

保留选区的密码显隐，自定义事件不携带密码。

<mo-password>
06 / INTERVAL SLIDER

双端区间滑块

双原生滑块、不可交叉区间与最小间距。

<mo-range-slider>
07 / PREFERENCE CONSENT

偏好确认面板

明确区分必要和可选偏好，不自行写入 Cookie、存储或启动服务。

<mo-consent>
08 / DELIBERATE POPUP

主动确认弹窗

原生模态弹窗、焦点返回、Escape 关闭与可取消确认事件。

<mo-cta-popup>
09 / VALIDATION SUMMARY

表单错误摘要

把原生校验消息整理为可跳转到真实字段的链接，不传出字段值。

<mo-validation-summary>
ONE REAL FORM

把细节，放进一个完整流程。

为你的摄影计划选择类型和印量，提交查看结果，或随时恢复初始选择。

选好以后，看看你的计划。
FOUR LITTLE GESTURES

确认，也可以是一笔轻轻的描线。

点击原生按钮播放。结束后描线自动离开，内容与焦点保留。
