Use them in Windows desktop software

They are standard Custom Elements + CSS + Web Animations, so they run wherever a modern web view renders your UI.

Electron

// renderer.js (bundled)
import { defineComponents } from
  'use-scroll-animate/components';
defineComponents();

Tauri

// src/main.ts — Vite + WebView2
import { defineTextComponents } from
  'use-scroll-animate/components/text';
defineTextComponents();

WebView2 · WinUI 3 / WPF

<!-- wwwroot/index.html, mapped via
     SetVirtualHostNameToFolderMapping -->
<script src="components.umd.js"></script>
<usa-spinner kind="fluent"></usa-spinner>

PWA / browser

<script src="https://unpkg.com/
  use-scroll-animate@2/dist/components.umd.js">
</script>
