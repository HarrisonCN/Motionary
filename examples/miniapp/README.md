# Motionary in a mini program (WeChat · Alipay · Douyin)

Mini programs cannot run Custom Elements, so `<usa-*>` tags do not work there. What carries over is the motion itself:
the same presets, durations and easings, exported as plain WXSS `@keyframes`.

```bash
npx motionary export --target wxss --presets fade-in-up,zoom-in,slide-up --rpx --out miniprogram/motionary.wxss
```

- `app.wxss` imports the generated file once: `@import "motionary.wxss";`
- Put `class="usa-fade-in-up"` on any `<view>`; set it when the view should enter (see `pages/index`).
- Reduced motion: add `usa-reduce-motion` to the page root from your own setting — mini program renderers do not all expose the OS
  reduced-motion setting, so the generated `@media (prefers-reduced-motion: reduce)` rule only helps where they do.
- `--rpx` converts px lengths to rpx (1px → 2rpx, 750 design width). Percent lengths stay percent.
- Alipay (ACSS) and Douyin (TTSS) read the same CSS: rename the file and the import.

Regenerate the file whenever you upgrade motionary; `motionary.wxss` here was generated by 12.1.
