# Open in StackBlitz

Small Vite projects that install `motionary` from npm, one per framework. Each shows a scroll reveal and a `<usa-switch>`
with its `usa:change` event. Each one was built with `vite build` against the published package before it was added.

| Framework | Open |
|---|---|
| Vanilla JS | [StackBlitz](https://stackblitz.com/github/HarrisonCN/Motionary/tree/main/examples/stackblitz/vanilla) · [source](./vanilla) |
| React 19 | [StackBlitz](https://stackblitz.com/github/HarrisonCN/Motionary/tree/main/examples/stackblitz/react) · [source](./react) |
| Vue 3 | [StackBlitz](https://stackblitz.com/github/HarrisonCN/Motionary/tree/main/examples/stackblitz/vue) · [source](./vue) |
| Svelte 5 | [StackBlitz](https://stackblitz.com/github/HarrisonCN/Motionary/tree/main/examples/stackblitz/svelte) · [source](./svelte) |

Solid and Angular are covered by the framework regression matrix ([docs/frameworks-matrix.md](../../docs/frameworks-matrix.md)),
not by a StackBlitz project yet.

Run locally: `cd examples/stackblitz/react && npm install && npm run dev`.
